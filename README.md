# EniGUI
EniGUI is a high-performance custom GUI framework for the Unity Editor, designed to replace IMGUI, UI Toolkit, and, in the future, uGUI.

The project is in an early development stage (draft), but it already demonstrates a well-thought-out rendering architecture and efficient resource management.

### Project Goal
- Provide a lightweight, high-performance, and extensible GUI system for Unity.
- Replace standard Unity GUI frameworks for the Editor and, eventually, for runtime UI.
- Offer low-level rendering control using CommandBuffer, Mesh, RenderTexture, and batching.
- Minimize allocations and draw calls for maximum performance.

### Future Development
- Support for interactive elements (buttons, sliders, input fields)
- Runtime UI support (replacement for uGUI)
- Customizable styles and themes
- Rendering optimization for large scenes and thousands of elements

### Project Status
- Core architecture implemented
- Batching, rendering, and resource management work
- No full set of UI elements yet
- Functionality will be expanded in future development
